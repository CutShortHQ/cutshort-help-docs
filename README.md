# Cutshort Help docs

Public Mintlify site source for Cutshort employer and candidate help. **No secrets** — safe to publish.

Canonical copy is maintained in [`cutshort-marketing/cutshort-help-articles`](https://github.com/CutShortHQ/cutshort-marketing). This repository is a **public mirror** so [Mintlify](https://mintlify.com) can deploy without access to private GitHub repos. Sync with `cutshort-marketing/scripts/sync-public-help-docs.sh`.

## Live site

- Preview: `https://cutshort-for-employers.mintlify.app`
- Custom domain: `https://docs.cutshort.io`

## Local preview

```bash
npx mintlify dev
```
