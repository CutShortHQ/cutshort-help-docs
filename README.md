# Cutshort Help docs

Public Mintlify site source for Cutshort employer and candidate help. **No secrets** — safe to publish.

Canonical copy is maintained in the private monorepo at `cutshortio/docs/help/`. This repository is a **public mirror** so [Mintlify](https://mintlify.com) can deploy without access to private GitHub repos.

## Live site

- Preview: `https://cutshort-for-employers.mintlify.app`
- Custom domain: `https://docs.cutshort.io`

## Local preview

```bash
npx mintlify dev
```
